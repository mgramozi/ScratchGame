# Scratch Game
Hi! This is my Scratch game. 🦔🎈
In this game, you control a little hedgehog whose mission is to pop all the spheres falling from the sky. Use the Left and Right arrow keys on your keyboard to move around. Be careful if you let 3 spheres slip past you, you lose!
Playing Online
1. Go to the [Scratch Website](https://scratch.mit.edu).
2. Click Create at the top to open the editor (or go straight to the [Scratch Editor](https://scratch.mit.edu/projects/editor/)).
3. In the top menu, click File > Load from your computer.
4. Choose the `scratchgame.sb3` file from this repository to load the game.
5. Click the Green 🟢 flag above the display screen to start playing!
Game Controls
- Left: Move left
- Right: Move right
- Goal: Pop as many spheres as you can! You have 3 lives miss 3 spheres and it's game over.
